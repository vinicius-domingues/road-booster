# Atualizar Linguagens

Copie o prompt abaixo e envie para a IA quando quiser verificar atualizações ou novas versões de linguagens e ferramentas.

---
**PROMPT:**

Aja como um Engenheiro de Software Senior e atualize as linguagens e ferramentas do meu projeto baseadas na estrutura do arquivo `road-booster-center/script.js`.

**Instruções:**
1. Verifique as ferramentas (`tools`) nos `topics` das variáveis `backendPhases`, `frontendPhases` e `extraRoadmaps`.
2. Identifique se houve o lançamento recente de alguma versão "major" ou se alguma linguagem/framework importante foi descontinuada (ex: mudanças drásticas no React, nova versão LTS do Node.js, do C#, etc.).
3. Adicione ou modifique o array `tools` (com `name` e `why`) refletindo o status atual do mercado.
4. Gere o código javascript atualizado com as substituições exatas para eu aplicar no arquivo.
